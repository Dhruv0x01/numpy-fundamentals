NumPy Fundamentals

Each folder focuses on one concept, with simple Python examples to understand how NumPy works and how it differs from standard Python data structures.

Structure
Each topic folder typically contains:

- `.py` files – Python scripts demonstrating the NumPy concept
- Comments – short explanations for clarity
